# Лабораторная работа 5. Тестирование API

## Описание
Покрытие REST API автоматическими тестами (Unit и Integration).

## Запуск тестов
```bash
pip install -r requirements.txt
pytest -v
```

## Запуск приложения
```bash
docker compose up --build
```

Приложение доступно по адресу: http://127.0.0.1:8004/docs
