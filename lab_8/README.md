# Лабораторная работа 8. Nginx reverse proxy и безопасность

## Описание
Развертывание приложения за веб-сервером Nginx (Reverse Proxy), раздача статики, настройка CORS и защита API.

## Архитектура
- **Nginx** — принимает запросы на порту 8007, раздает статику (`index.html`) и проксирует запросы к API.
- **FastAPI (web)** — обрабатывает бизнес-логику (доступен только внутри Docker-сети).
- **PostgreSQL (db)** — хранит данные.
- **CORS** — настроен в `main.py` для безопасного взаимодействия с фронтендом.
- **Защита от SQL-инъекций** — используются параметризованные запросы SQLAlchemy.

## Как запустить
1. Откройте терминал в папке `lab_8`.
2. Выполните: `docker compose up --build`
3. Главная страница (статика): http://127.0.0.1:8007
4. Документация API (через Nginx): http://127.0.0.1:8007/api/docs
