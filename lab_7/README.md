# Лабораторная работа 7. Транзакции и оптимизация запросов

## Описание
Реализация безопасных транзакций перевода денег между счетами.

## Как запустить
1. Откройте терминал в папке `lab_7`.
2. Выполните: `docker compose up --build`
3. Откройте: http://127.0.0.1:8006/docs

## Что реализовано
- **Транзакции:** перевод денег атомарен (либо переводится всё, либо ничего).
- **Конкурентность:** используется `SELECT ... FOR UPDATE` для блокировки строк на время транзакции, чтобы избежать "гонки данных" (race condition).
- **Индексы:** поле `owner_email` в таблице счетов проиндексировано для быстрого поиска.
