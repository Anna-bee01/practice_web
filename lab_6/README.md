# Лабораторная работа 6. Аутентификация и работа с базой данных

## Описание
REST API на FastAPI с подключением к PostgreSQL, регистрацией, JWT-аутентификацией и защищенными эндпоинтами.

## Как запустить
1. Убедитесь, что установлен Docker Desktop.
2. Откройте терминал в папке `lab_6`.
3. Выполните команду:
   ```bash
   docker compose up --build
4. Откройте в браузере документацию: http://127.0.0.1:8005/docs

## Что реализовано
1. База данных: PostgreSQL (через SQLAlchemy).
2. Миграции: Таблицы создаются автоматически при старте (через Base.metadata.create_all).
3. Аутентификация: Хэширование паролей (bcrypt) и выдача JWT-токенов (python-jose).
4. Защита: Метод /profile доступен только с валидным токеном.
