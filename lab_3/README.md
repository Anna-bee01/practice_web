# Лабораторная работа 3. Валидация и обработка ошибок в API

## Описание
REST API на FastAPI с валидацией входных данных, реализацией бизнес-правил и логированием ошибок.

## Как запустить
1. Убедитесь, что установлен Docker Desktop.
2. Откройте терминал в папке `lab_3`.
3. Выполните команду:
   bash
   docker compose up --build
4. Откройте в браузере интерактивную документацию: http://127.0.0.1:8002/docs

## Что реализовано
1. Валидация данных: проверка типов, формата (EmailStr), диапазона (возраст 18-120), длины (пароль от 8 символов).
2. Кастомные валидаторы: имя только из букв, пароль должен содержать буквы и цифры.
3. Бизнес-правила: проверка на уникальность email (возвращается статус 409 Conflict).
4. Обработка ошибок: возвращаются структурированные JSON-ответы с кодами (400, 404, 409, 422, 500).
5. Логирование: все события и ошибки записываются в файл app.log и выводятся в консоль.
