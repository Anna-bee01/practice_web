# Лабораторная работа 2. REST API для CRUD операций

## Описание
REST API для управления пользователями (User) на FastAPI.

## Как запустить
1. Откройте терминал в папке `lab_2`.
2. Выполните:
   ```bash
   docker compose up --build
3. Перейдите в браузере по адресу: http://127.0.0.1:8001/docs

## Эндпоинты
1. GET /users — список всех пользователей
2. POST /users — создание пользователя
3. GET /users/{id} — получение пользователя по ID
4. PUT /users/{id} — обновление пользователя
5. DELETE /users/{id} — удаление пользователя
